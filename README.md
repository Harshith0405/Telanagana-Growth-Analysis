\# Telangana Growth Analysis 📊



\## Project Overview



Telangana Growth Analysis is a data analytics project focused on understanding the economic and developmental growth patterns of Telangana state.



The project analyzes multiple government-related datasets including investment approvals, transportation growth, and registration trends to identify district-wise development patterns and economic indicators.



The objective of this project is to transform raw datasets into meaningful insights using Python, SQL, and Power BI.



\---



\# Problem Statement



Government and economic datasets contain large amounts of information about different sectors. Extracting meaningful insights from this data helps understand:



\- Which districts are experiencing higher growth

\- Investment distribution across regions

\- Industrial development patterns

\- Transportation growth trends

\- Economic activity changes over time



This project provides a data-driven approach to analyze Telangana's growth.

\# Dataset Description



The project uses multiple datasets:



\## 1. District Dimension Dataset



File:



dim\_districts.csv





Contains information about Telangana districts.



Purpose:

\- District identification

\- Regional comparison

\- Mapping analysis





\---



\## 2. Date Dimension Dataset



File:



dim\_date.csv





Contains time-related information.



Purpose:

\- Year-wise analysis

\- Trend identification

\- Growth comparison





\---



\## 3. TS-iPASS Investment Dataset



File:



fact\_TS\_iPASS.csv





Contains industrial investment approval details.



Used for analyzing:



\- Industrial growth

\- Investment distribution

\- Sector-wise development

\- District-wise investments





\---



\## 4. Stamp Registration Dataset



File:



fact\_stamps.csv





Used to analyze:



\- Property registration trends

\- Economic activity

\- Regional growth patterns





\---



\## 5. Transportation Dataset



File:



fact\_transport.csv





Used for analyzing:



\- Vehicle registrations

\- Transportation growth

\- District mobility patterns
